# Finio — Feature Inventory

*Last updated: 2026-07-25*

---

## Built and working

### Auth
- [x] Register with email + password (Zod validation + BCrypt)
- [x] Email verification (token emailed, 24 h expiry)
- [x] Resend verification email
- [x] Login with JWT (remember me = localStorage, session only = sessionStorage)
- [x] Logout (clear storage)
- [x] Forgot password → OTP emailed → reset password
- [x] Change password (requires current password + OTP verification)
- [x] Live password-strength checklist (8 chars, uppercase, number, special char) on register, forgot-password step 2, and settings change-password
- [x] Update display name
- [x] User preferences (currency, theme, budget alert threshold)
- [x] GDPR data export (all user data as JSON)
- [x] Account deletion (removes all data)
- [x] Rate limiting on auth endpoints (Bucket4j, 10 req/min per IP)

### Transactions
- [x] Create / read / update / delete

- [x] Bulk delete (checkbox select)
- [x] Tags (free-form, multi-tag per transaction)
- [x] Duplicate detection (warns on same category + amount within recent period)
- [x] Export all transactions as CSV
- [x] Monthly summary (total income, total expenses, net balance)
- [x] Summary range (last N months, for charts)
- [x] Calendar view (transactions grouped by day)
- [x] Category spending trends (last N months, for charts)

### Categories

## FREE plan limits

| Feature | FREE limit |
|---|---|
| Transactions | Unlimited |
| Categories (custom) | Unlimited |
| Budgets per month | 3 |
| Goals | Blocked |
| Recurring transactions | Blocked |
| Net Worth | Blocked |
| CSV Import | Blocked |
| Monthly Reports | Read-only (auto-generated for all) |

## Deferred / not built

| Item | Notes |
|---|---|
| Mobile app | No React Native or PWA manifest. Responsive web only. |
| Push notifications | No FCM, no web push. Budget alerts are email-only. |
| Bank feed integration (Plaid/Open Banking) | Manual entry and CSV import only. |
| Multi-currency conversion | Currency is a display preference, not a conversion engine. All amounts stored as-is. |
| Shared accounts / household mode | Single user per account. |
| Transaction attachments (receipt photos) | Not implemented. |
| Audit log | No history of what changed or when. |
| Two-factor authentication (TOTP) | OTP for password change only; no login 2FA. |
| Social login (Google, GitHub) | Email + password only. |
| PDF report export | Reports are on-screen only. |
| Budget rollover | Each month is independent. |
| Transaction split | One category per transaction. |
| Savings rate / financial health score | No composite metrics beyond income/expense/balance. |
| Admin: impersonate user | Not implemented. |
| Admin: dispute resolution / refund flow | Manual via Stripe dashboard. |
